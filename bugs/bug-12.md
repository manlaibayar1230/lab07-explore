# BUG-12: `POST /api/books` буруу JSON биетэй хүсэлтэд 400 биш `200 OK {"result":"OK"}` буцаадаг

**Орчин:** Уншлагын жагсаалт v2.0, `curl` (Git Bash), Windows 11 Pro, 2026-11-25
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд (Git Bash/Linux):
   `curl -s -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title": "abc", bad json'`
2. `curl -s -i -X POST localhost:3000/api/books -d 'буруу оролт'`
3. `curl -s -i localhost:3000/api/books` — номын жагсаалтыг шалгана.

(PowerShell-д `curl.exe` гэж бичиж, биеийг файлд хадгалаад `--data-binary "@body.json"`-ээр илгээнэ.)

**Хүлээгдэж байсан:** «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»
**Бодит үр дүн:** Алхам 1, 2 хоёулаа `HTTP/1.1 200 OK` ба `{"result":"OK"}` буцаана. Алхам 3: ном нэмэгдээгүй (3 ном хэвээр) — өөрөөр хэлбэл сервер хүсэлтийг хэрэгжүүлээгүй ч клиентэд «амжилттай» гэж худал хариулдаг.

**Ноцтой байдал:** Major — API-ийн гэрээг зөрчиж, клиент алдааг илрүүлэх боломжгүй (өгөгдөл чимээгүй алдагдана); интеграци, автомат клиентүүдэд хамгийн аюултай төрлийн алдаа.
